## Переобучение модели

Готовые прогнозы за август и сентябрь и метрики валидации хранятся в
`artifacts/own_model`. Их достаточно для работы экрана инференса вместе
с основной выгрузкой.

Для повторного обучения извлеките только `IAVD_3.7_ML_team/course_pack/cards_practice.csv`
из учебного архива `IAVD_3.7_ML_team.zip` в `data/cards_practice.csv`.
Обучение использует из этого CSV идентификаторы карточек, чтобы исключить их
из обучающей и валидационной выборок.

```bash
.venv/bin/python -m soc_dashboard.train
```

Команда пересчитает прогнозы и метрики и сохранит обученную модель
локально в `artifacts/own_model/model.joblib`.
