Поместите файл `iavd_ml_dataset.parquet` в эту папку. В раздаче курса он лежит в
`Datasets → Задание 2: Инференс модели → Под обучение` и в
`3.6_Пр_Интеграция_ML`. Это две копии одной выгрузки.

SHA-256 выгрузки, на которой получены результаты отчёта

```text
e70e1613e6a8f4fcf189553bd05155852846e87d5ea0ec693b45b2a20c1bcf0c
```

Если материалы уже лежат в корне проекта, можно подключить файл через ссылку:

```bash
ln -s '../ИАиВД_Материалы/3.6_Пр_Интеграция_ML/iavd_ml_dataset.parquet' data/iavd_ml_dataset.parquet
```
